# Explicit page-start spacing

The two matrix documents contain the same sixteen paragraph/run-break controls: zero and
nonzero spacing, distances below and above eight points, 8/12/18pt type, and keep
settings. The second adds unrelated centered/wrapped prose. Word16 exports in
Final and AllMarkup preserve each target gap across that transformation.

`office.json` pins sources, references and measured baselines. Authored-point
consumption and PDF rounding/font-seat residuals are separate: keep the original
image thresholds and report remaining absolute geometry failures. Scaled print,
contextual, automatic and line-relative spacing retain explicit fallbacks pending
independent qualification. No font-metric calibration is derived from these gaps.

The held-out `composition.docx` combines equations, inline pictures, a table and a
selected static header. Word consumes the same six-point excess after direct
paragraph predecessors; a table boundary preserves the full 24pt before-spacing.
Both presets retain all eight source pages and their supported content.
