# Independent mixed-table documents

Generated by `tools/NewMixedTableFixtures.py` using handwritten OOXML and a small
opaque blue/orange PNG. These are public synthetic records with independent
structure; they do not derive from the existing report portfolio template.

`maintenance-matrix.docx` has four rows and three columns with automatic heights.
`capacity-schedule.docx` is the held-out five-row/four-column minimum-height
schedule. Each contains wrapped prose, a picture followed by a caption, display
and inline mathematics, and a nested record followed by ordinary text.

`expected.json` pins input hashes, authored labels, math, table dimensions and
picture sizes. Content must paint completely, once, in source order within each
cell. The nested record consumes the preceding measured display advance; changing
that advance moves both the record and its following text by the same amount.
Automatic/minimum rows admit this content. No exact-height crop contract, new
Office comparison or application-view calibration is claimed by these sources.
